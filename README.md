# MSTFAXWSF-a-web-security-asessmet-framework
MSTFAXWSF  A black-and-red terminal framework that chains Katana, FFUF, WhatWeb, Nikto and Nuclei into one automated web security assessment. Type a domain, get live output and a professional HTML + JSON report.  Pure Python standard library: no pip install, nothing heavy. Built for Kali Linux (any Debian-based distro works).  Authorized use only.
